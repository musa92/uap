# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: assume good faith, critique the work rather than the person, and
accept that a technical disagreement can end with the maintainers deciding.

Report unacceptable behaviour through GitHub's private reporting on this
repository. Reports are handled by the maintainers listed in
[MAINTAINERS.md](./MAINTAINERS.md).
