This project is newly public and currently has one maintainer. Sustained
contribution in an area is the path to being listed here, and the intent is for
this table to stop naming one person.

Decisions are made by consensus among maintainers on the public pull request or
discussion. Where consensus is not reached the change does not land, because a
protocol defaults to not changing.

Changes to the three invariants in SPEC.md §6, §7 and §9 require two independent
interoperating implementations, regardless of maintainer agreement.
