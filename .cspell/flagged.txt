# NOTE ON CASING. Wrong casings are not listed here. cspell matches flagWords
# case-insensitively, so flagging "adsense" would also reject "AdSense". Casing
# is enforced by caseSensitive:true in .cspell.json plus the correct form in a
# dictionary: AdSense, OpenRTB, Ed25519 and EdDSA are listed, so any other
# casing fails as an unknown word.
